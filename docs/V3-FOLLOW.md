## 작업을 시작할 때마다 (Claude Code)

1. `../v2.7.7/package.json` 의 `version` 을 본다. 위 표보다 높으면
2. `../v2.7.7/CHANGELOG.md` 에서 그 사이 항목을 읽고 아래 «분류» 표에 한 줄씩 넣는다
   - **반영** — 이미 옮긴 기능이 바뀌었다 → 이번 작업 전에 고친다 (규칙이면 `src/domain` 시험부터)
   - **그 단계에서** — 아직 안 옮긴 기능이다 → 그 기능을 옮길 때 최신 모양으로 옮긴다
   - **해당 없음** — 웹 구조에선 생기지 않는 문제 (예: v3 의 이월 · 흔적 · 로컬 DB · Electron 서명)
   - **확인** — 판단이 애매하다 → 소유자에게 묻는다
3. `styles.css` 가 바뀌었으면 `cp ../v2.7.7/src/styles.css src/v3/styles.css` 로 통째로 바꾼다 (손대지 않은 원본이어야 한다. 웹에서만 다른 것은 `src/pc/pc.css`)
4. 위 «지금 따라잡은 곳» 표의 버전을 올리고, **웹 `package.json` 의 `version` 도 같은 v3 버전으로** 올린다 (2026-10-30 소유자 — 웹 버전 = 따라잡은 v3 버전)
5. `npm run v3` 로 확인한다 — 기획(분류) · 스타일 원본 · 구현(아직 안 옮긴 줄)을 한 번에 보여 준다
